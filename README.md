# LatestGovtJobs Automation — Laravel 13

This repository is the first development build for the approved LatestGovtJobs.co.in automation plan. It is deliberately **code-first, AI-last, human-approved**.

The project includes government source management, deterministic crawling and change detection, recruitment filtering, draft creation, human review, crawler health tracking, AI budget controls, PDF/OCR/browser fallback service paths, and publishing isolation.

See IMPLEMENTATION_STATUS.md after the first code import for the current build status.
